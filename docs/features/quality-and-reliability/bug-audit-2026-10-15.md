## Remaining findings

- Reproduced, unfixed: a directory entry cap can hide a `.git` marker and allow
  discovery of nested repositories. Add a real parent/nested fixture with
  injected enumeration order `[nested, .git]` and a one-entry budget, then
  inspect the marker directly when enumeration is incomplete. Preserve linked
  marker refusal and stop traversal on inspection errors.
- Needs dedicated regression: rename detection may omit the original path
  from conflict forecasting's changed-file set. Check rename/delete and
  rename/modify divergence before changing the heuristic.
- Needs end-to-end reproduction: profile restoration appears to restore
  persisted schedule data without refreshing the schedule runtime.

restored the investigation scope and retained frequent pushes. Existing remote
branches, installations, profile recovery records, and the unfinished
installed-clone acceptance work were left intact. No temporary task branches,
