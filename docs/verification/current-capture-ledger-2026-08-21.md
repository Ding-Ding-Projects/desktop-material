## How to close a row

1. Build the Windows desktop application from the intended commit.
2. Use the approved headless capture route and `script/capture-app.js` only
   against that built artifact.
3. Save the PNG under `docs/assets/screenshots/<ledger-id>.png` and record the
   exact capture commit in the ledger.
4. Run the focused coverage contract after the source and receipt are present.

Do not rename, rebuild, or restore the reverted shell in order to satisfy this
inventory. A row is evidence for the current UI, not a request to change it.
