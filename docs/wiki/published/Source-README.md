# Desktop Material wiki source

This repository publishes Desktop Material's complete wiki articles. Start at
[Home](Home.md), [User Guide](User-Guide.md), or [Developer Guide](Developer-Guide.md).
The [Windows startup repair](Windows-Startup-Repair.md) article records the native
argument-parser replacement and separates source checks from package and installed
acceptance.

The application source, root build entrypoints, roadmap and release evidence live
in [Ding-Ding-Projects/desktop-material](https://github.com/Ding-Ding-Projects/desktop-material).
This wiki contains documentation only and has no executable or installable target.
Its root build commands return 2 with that explicit nonapplicability reason.

GitHub's wiki publishes `master`. Keep that load-bearing branch. The synchronized
`main` ref preserves the same completed documentation for integration readback;
it does not replace the wiki publication branch.
