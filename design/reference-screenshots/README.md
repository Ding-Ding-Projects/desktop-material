# Reference screenshots

Working reference images — competitor screenshots, mockups, anything captured to
describe a feature before it is built. **The image files here are gitignored.**
This README is the only tracked file in the directory.

They are ignored deliberately: they are usually screenshots of other people's
software, kept as a working reference while a feature is being built, and they
have no business in the repository's history or in a public clone.

The features these describe are written out in words in `HANDOFF.md`, under
"REQUESTED FEATURES, recorded before they are built", so the descriptions
survive without the images.
