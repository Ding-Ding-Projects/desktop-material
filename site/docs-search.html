Search every published documentation page. Plain text matches anywhere in a page; enable Regular expression to use a pattern, or build one below without writing it by hand.

Plain text is the default. A regular expression is only ever treated as a pattern once Regular expression is switched on, and it is then evaluated in an isolated worker that this page stops after a hard 750 ms deadline, so a pattern such as ^(a+)+$ cannot freeze the page. Patterns are capped at 512 characters. Nothing you type here leaves your browser.
